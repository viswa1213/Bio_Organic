### 📋 Prerequisites

Before you begin, ensure you have the following installed:

<p>
  <img src="https://img.shields.io/badge/Node.js-v18_or_higher-339933?style=for-the-badge&logo=nodedotjs&logoColor=white"/>
  <img src="https://img.shields.io/badge/npm-v9_or_higher-CB3837?style=for-the-badge&logo=npm&logoColor=white"/>
  <img src="https://img.shields.io/badge/MongoDB-Local_or_Atlas-47A248?style=for-the-badge&logo=mongodb&logoColor=white"/>
</p>

### <img src="https://media.giphy.com/media/VgCDAzcKvsR6OM0uWg/giphy.gif" width="25"> Quick Start

```bash
# 1️⃣ Clone the repository
git clone https://github.com/viswa1213/Bio_Organic.git

# 2️⃣ Navigate to the project directory
cd Bio_Organic

# 3️⃣ Navigate to Backend directory
cd Backend

# 4️⃣ Install dependencies
npm install

# 5️⃣ Create environment file and add your MongoDB connection string
# Edit the .env file and add: Mongo_Url=your_mongodb_connection_string
cp .env.example .env  # Or create manually

# 6️⃣ Start the server
node server.js
```

### <img src="https://media.giphy.com/media/WFZvB7VIXBgiz3oDXE/giphy.gif" width="25"> Environment Variables

Create a `.env` file in the `Backend` directory:

```env
Mongo_Url=mongodb+srv://your_username:your_password@cluster.mongodb.net/bio_organic
```
